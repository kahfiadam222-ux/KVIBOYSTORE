# Kviboystore Design System

Folder ini berisi **Figma design captures** sebagai referensi visual untuk implementasi UI.

## Design Files

Setiap file .dc.html adalah export dari Figma yang menunjukkan:
- Layout & responsive behavior
- Color scheme (Aurora Pastel: putih 60%, glow 30%, indigo 10%)
- Typography & spacing
- Component states (hover, active, disabled)

## Desain Tersedia

- **Katalog** — Beranda, grid produk (2-7 kolom), search/filter
- **Katalog Gelap** — Dark mode version
- **Katalog Mobile** — Responsive layout untuk HP
- **Product Detail** — Halaman produk individual + reviews
- **Cart** — Keranjang belanja
- **Checkout** — 3-step payment flow
- **Login/Signup** — Authentication forms
- **Admin Dashboard** — KPI cards, management UI
- **Seller Analytics** — Dashboard penjualan
- **Order History** — Tracking & status
- **User Profile** — Account settings
- **Wishlist** — Favorit produk
- **Notifications** — Alert & message center
- **Partners** — Partnership landing page
- **Sidebar** — Navigation panel (desktop & mobile)
- **Search Filter** — Advanced search interface

## Cara Menggunakan

1. Buka .dc.html file di browser untuk preview design
2. Gunakan sebagai referensi saat implementasi komponen React
3. Cross-check responsive behavior di mobile (menggunakan Chrome DevTools)
4. Pastikan warna & spacing sesuai dengan nilai design tokens

## Design System

**Color Palette (Aurora Pastel):**
- Primary: #4338CA (Indigo)
- Sky Blue: #93C5FD
- Lavender: #C4B5FD
- Background: White
- Text: Dark gray

**Typography:**
- Font: Inter (sans-serif)
- Sizes: 12px, 14px, 16px, 18px, 24px, 32px
- Weights: 400, 500, 600, 700

**Spacing:**
- Base unit: 4px
- Gaps: 8px, 12px, 16px, 24px, 32px, 40px

**Border Radius:**
- Small: 8px
- Medium: 12px
- Large: 16px, 20px

Untuk perubahan design, update di Figma dan export ulang .dc.html files.
